# مولّد بطاقات الوصف الوظيفي

تطبيق ويب صغير (Flask) ينفّذ المواصفة الواردة في
[`job-description-card-generator-prompt.md`](../job-description-card-generator-prompt.md):
يستقبل مسمى وظيفي واحد، يحدد مستواه الإداري، يُدمج نص "المهام والمسؤوليات
الأساسية" الثابت للمستوى المطابق، يولّد "الهدف العام" و"المهام المتخصصة"
و"المؤهلات" بحسب المستوى، وينتج بطاقة Word قابلة للتنزيل — مع أرشفة كل مسمى
سبق توليده لعدم إعادة توليده مرتين.

## التشغيل محليًا

```bash
cd webapp
python3 -m venv .venv
source .venv/bin/activate        # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على: <http://localhost:5000>

> هذا تطبيق يعمل على جهازك (أو أي خادم تنشره عليه) — لا يوجد رابط عام مستضاف
> حاليًا؛ التعليمات أعلاه هي طريقة تشغيله وعرضه في متصفحك.

## توليد بمحتوى مبني على مصادر (اختياري لكن مُوصى به)

بدون مفتاح API، يستخدم التطبيق صياغة احتياطية عامة للأقسام 2 و4 و5 (معلَّمة في
الواجهة بوضوح) حتى تبقى الأداة قابلة للتجربة دون اتصال خارجي. للحصول على محتوى
مبني فعليًا على الأطر المرجعية المذكورة في المواصفة (SASCO/ISCO-08/O\*NET/ESCO
وأطر التخصص)، عيّن مفتاح Anthropic API قبل التشغيل:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
python app.py
```

## القسم 3 (المهام الأساسية) لا يُولَّد بالذكاء الاصطناعي أبدًا

نصوص القسم 3 مُثبَّتة كقيم جامدة في `core_templates.py` (منسوخة حرفيًا من
المواصفة)، ويتم فقط اختيار القالب المطابق للمستوى واستبدال اسم المجال — دون أي
استدعاء للنموذج اللغوي، تمامًا كما تنص المواصفة.

## الأرشفة (History / Cache)

كل مسمى وظيفي (بعد التطبيع) يُخزَّن في `data/job_descriptions.db` (SQLite).
تكرار نفس المسمى يعيد النسخة المحفوظة فورًا دون توليد جديد؛ زر "إعادة التوليد"
في الواجهة يُنشئ نسخة (`version`) جديدة صراحةً بدلاً من الكتابة فوق القديمة.

## بنية المشروع

```
webapp/
  app.py                 # مسارات Flask
  pipeline.py             # يجمع القسم الثابت (3) مع الأقسام المولَّدة (2، 4، 5)
  leveling.py             # اكتشاف المستوى الوظيفي واستخراج اسم المجال
  core_templates.py       # نصوص القسم 3 الثابتة (بدون ذكاء اصطناعي)
  content_generator.py    # توليد الأقسام 2/4/5 (LLM أو صياغة احتياطية)
  docx_builder.py         # بناء ملف Word النهائي
  db.py                   # الأرشفة/التخزين المؤقت (SQLite)
  templates/, static/     # واجهة المستخدم
```
